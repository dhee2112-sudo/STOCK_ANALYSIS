# Stock Analysis

## Overview

This project analyzes the historical price performance, returns, volatility, and correlations of selected Indian stocks using Python.

## Stocks Analyzed

- BEL
- Tata Steel
- Reliance
- Bharti Airtel

## Analysis Performed

- Historical closing price analysis
- Normalized price comparison
- Daily return analysis
- Daily volatility
- Annualized volatility
- Stock return correlation
- Cumulative returns
- Comparative visualizations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yFinance

## Key Findings

- BEL recorded the highest cumulative return among the selected stocks over the analyzed period.
- Tata Steel had the highest historical daily volatility among the selected stocks.
- Reliance had the lowest historical daily volatility among the selected stocks.
- The selected stocks showed positive but low-to-moderate correlations with each other.
- Tata Steel and Reliance had the highest correlation among the selected stocks, at approximately 0.40.

## Disclaimer
This project is for educational and analytical purposes only. Historical performance does not guarantee future results and this analysis should not be considered investment advice.
